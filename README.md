# 이탈리아 신혼여행

밀라노에서 로마까지 8박 10일 신혼여행 일정, 이동 방법, 비용을 담은 페이지입니다.

| 파일 | 내용 |
|---|---|
| `italia.html` | 페이지 원본 (claude.ai 아티팩트로 게시) |
| `trip.json` | 일정·비용 데이터 |
| `docs/` | 휴대폰 홈 화면 앱. `python3 tools/build_app.py`로 만듦 |

## 휴대폰 앱으로 쓰기

1. GitHub 저장소 **Settings → Pages**에서 *Source*를 **Deploy from a branch**로, 브랜치를 이 브랜치, 폴더를 **/docs**로 정하고 저장합니다.
2. 1~2분 뒤 나오는 주소(`https://<아이디>.github.io/<저장소>/`)를 휴대폰에서 엽니다.
3. 홈 화면에 추가합니다.
   - 아이폰 Safari: 공유 버튼 → **홈 화면에 추가**
   - 안드로이드 Chrome: 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**
4. 한 번 열고 나면 인터넷이 없어도 열립니다.

앱에서 고친 내용은 그 휴대폰에만 저장됩니다. 두 사람이 맞추려면 **내보내기**로 파일을 보내고 받은 쪽에서 **가져오기**를 누르세요.

`italia.html`이나 `trip.json`을 바꾼 뒤에는 `python3 tools/build_app.py`를 다시 실행해 `docs/`를 갱신합니다.
